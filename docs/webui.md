# AI Agent Harness WebUI 设计文档（v1.2）

> **版本**：v1.2
> **定位**：面向复杂真实任务的 AI Agent 执行框架可视化界面。
> **风格基准**：DeepSeek Harness WebUI（浅色默认、深色侧边栏、高信息密度对话流、实时底部指标带）

---

## 1. 设计原则

### 1.1 核心原则

| 原则                 | 说明                                                                                                                                             |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| **透明即信任** | 每一步的"判断"由模型做出，每一步的"事实"由 harness 记录。UI 必须让三方记录（TurnContract 声明、Capacity 授权、Step trace 实际）可对照、可 diff。 |
| **层级可视化** | Session-Turn-Step 三层结构在界面中有明确空间映射，任何 UI 元素可定位到"哪次输入、哪个子任务、哪个最小动作"。                                     |
| **实时可观测** | 成本、延迟、token 消耗、缓存命中率等数据必须实时呈现，而非仅在结束后展示。                                                                       |
| **契约前置**   | 路由决策、预算分配、权限校验的结果必须在执行前以可视化方式呈现，让用户"看到授权"。                                                               |
| **反馈闭环**   | 用户反馈（决策更改、授权操作、输出评价）的入口必须嵌入在对应事件的上下文附近，而非集中到会话末尾。                                               |

### 1.2 视觉风格

- **图标风格**：全站统一使用简单线条图标（1.6px stroke、圆角端点、单色 `currentColor`）；不使用彩色 emoji 作为图标。

- **默认主题**：浅色模式（`#ffffff` 主背景，`#f9fafb` 消息区，`#f3f4f6` 代码块背景）
- **深色模式**：可配置切换（通过设置或系统偏好）
- **侧边栏**：固定深色（`#1f2937` 或 `#111827`），与主内容区形成强烈对比，突出导航层级
- **字体**：系统字体栈（`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`）+ 等宽字体用于代码（`Menlo, Monaco, Consolas, monospace`）
- **密度**：高信息密度，消息内嵌套子步骤（思考→代码→工具调用），支持折叠/展开

## 3. 核心区域设计

### 3.1 顶部栏（Top Bar）

```
┌─ Top Bar ─────────────────────────────────────────────────────────────────┐
│  [🔷 deepseek HARNESS]  [➕ 新会话]  │  读取 AGENT.md及设计文档           │
│                                       │  [4 个子代理 ▼] [13 个后台任务 ▼] │
│                                                                       [Session 日志 ▼] │
└───────────────────────────────────────────────────────────────────────────┘
```

**设计要点**：

- **左侧**：品牌 Logo（`deepseek` + `HARNESS` 标签）+ **新会话按钮**（带 + 图标，常驻入口）
- **中间**：当前激活 Session 的标题（从 `UserInteractionRecord.rawInput` 提取或模型生成）
  - 标题右侧：子代理下拉（显示并行子代理数量及状态）+ 后台任务下拉（显示后台任务列表）
- **右侧**：`Session 日志` 按钮（下拉菜单，可查看事件流、导出日志、回放）
- **高度**：48px，底部 1px 边框 `#e5e7eb`，背景白色

---

### 3.2 个人中心（右上角下拉抽屉）

**入口**：Top Bar 右侧人形图标；点击展开下拉抽屉，点击外部区域收起。
**内容**：画像、账本、设置。画像和账本不再作为左侧边栏一级导航。

### 3.3 左侧边栏（Sidebar）

**背景色**：`#1f2937`（深灰，与主内容区形成对比）
**宽度**：240px，可折叠为 60px 图标模式

```
┌─ Sidebar ─────────────────────────────────┐
│  [＋ 新会话]                              │
├───────────────────────────────────────────┤
│  工作区                      [search] [+] │
├───────────────────────────────────────────┤
│  会话 · N                                 │
│  ├─ 读取设计文档             6分钟        │
│  ├─ 实现功能文档             19天         │
├───────────────────────────────────────────┤
│  [settings] 设置                          │
└───────────────────────────────────────────┘
```

**设计要点**：

- **新会话按钮**：Sidebar 顶部，点击创建简单的新会话。
- **工作区头部**：只保留搜索和新建工作区两个图标；排序/组织图标移除。
- **新建工作区**：点击 `+` 后通过路径选择工作区空间；它与顶部“新会话”的简单会话创建语义不同。
- **分组命名**：默认分组使用“会话”，不使用“未分组”。
- **会话条目**：显示名称、状态、轮次、成本和相对时间；当前激活会话使用左侧竖线和浅蓝高亮。
- **底部**：设置入口保留在侧边栏；画像与账本从侧边栏移除，进入个人中心。
- **字体颜色**：白色/浅灰（`#f3f4f6`），次要文字 `#9ca3af`

### 3.4 对话流（Chat Flow）

消息按时间顺序垂直排列，无传统"气泡"边框，采用扁平卡片式布局。

#### 3.4.1 消息类型卡片

**思考（Thinking）**：

```
┌─ Message Card ────────────────────────────────────────────┐
│  💭 思考 · A background job notification: bash-11 (web    │
│    serve.mjs) finished with exit 143 (SIGTERM). That's    │
│    one of our earlie...                                   │
│                                                           │
│  [👍] [👎] [📋 复制] │ 用量 1.2K tok │ 用时 2.3秒 │ 01:23 │
└───────────────────────────────────────────────────────────┘
```

- 图标：💭（或灯泡图标）
- 标签："思考"
- 内容：灰色斜体或浅灰色文字，可折叠
- 背景：透明或极浅灰

**代码（Code）**：

```
┌─ Message Card ────────────────────────────────────────────┐
│  # 代码 · Read terminated web job output                  │
│                                                           │
│  [🔧 工具调用] job_output · bash-11                      │
│                                                           │
│  [👍] [👎] [📋 复制] │ 用量 340 tok │ 用时 0.4秒 │ 01:24 │
└───────────────────────────────────────────────────────────┘
```

- 图标：`#`（或代码文件图标）
- 标签："代码"
- 子级：工具调用卡片，缩进或嵌套显示

**工具调用（Tool Call）**：

```
┌─ Tool Call Card ──────────────────────────────────────────┐
│  🔧 工具调用 · job_output · bash-11                      │
│  参数: { path: "..." }                                   │
│  结果: (输出摘要...)                                      │
└───────────────────────────────────────────────────────────┘
```

- 嵌套在代码卡片内或作为独立卡片
- 背景：`#f3f4f6` 浅灰
- 左侧有竖线或缩进表示层级关系

**上下文注入（Context Injection）**：

```
┌─ Context Card ────────────────────────────────────────────┐
│  📋 上下文注入 · tool-jobs · bash MAZI_HOME=/tmp/mazi-vue │
│    MAZI_SERVER_PORT=4317 node apps/api/dist/main.js       │
└───────────────────────────────────────────────────────────┘
```

- 图标：📋（或文档图标）
- 标签："上下文注入"
- 内容：等宽字体，显示注入的上下文摘要

**普通文本消息（用户/助手）**：

```
┌─ Message Card ────────────────────────────────────────────┐
│  这两个是我在冒烟测试中启动的临时进程，后续被清理命令终止    │
│  （SIGTERM，exit 143），并非异常：                          │
│                                                           │
│  - bash-11（serve.mjs web 冒烟实例）                      │
│  - bash-10（后端 4317 冒烟实例）                          │
│                                                           │
│  清理时端口 4317/5174 上各自已存在可用的运行实例...        │
│                                                           │
│  👍 👎 📋 复制 │ 用量 2.3M tok │ 用时 12秒 │ 01:41      │
└───────────────────────────────────────────────────────────┘
```

- 用户消息：可带轻微背景色区分（如 `#f9fafb`）
- 助手消息：白色背景
- 支持 Markdown：列表、代码块、粗体、链接等

#### 3.4.2 消息元数据栏

每条消息底部统一显示操作与指标：

```
👍  👎  📋 复制  │  用量 2.3M tok  │  用时 12秒  │  01:41
```

| 元素    | 说明                                                                 |
| ------- | -------------------------------------------------------------------- |
| 👍 / 👎 | 点赞/点踩，记录`UserFeedback.type: output_rating`                  |
| 📋 复制 | 复制消息内容到剪贴板                                                 |
| 用量    | `Step.usage.vendor.inputTokens + outputTokens` 汇总，格式化（K/M） |
| 用时    | `Step.endedAt - Step.startedAt`，格式化（秒/分/时）                |
| 时间戳  | `HH:MM` 格式，悬停显示完整时间                                     |

### 3.5 输入区（Input Area）

固定在主内容区底部，会话流之上。

```
┌─ Input Area ──────────────────────────────────────────────┐
│  [➕]  ui按照docs/webui.md文档实现，用浅色，主题可配置深色模式 │
│                                                    [DeepSeek-V4-Flash High ▼] [↻] [⬆] │
└───────────────────────────────────────────────────────────┘
```

**设计要点**：

- **左侧 + 按钮**：添加附件、引用文件、快捷指令
- **中间输入框**：
  - 多行文本，支持 `Shift+Enter` 换行
  - 自适应高度，最大 8 行后滚动
  - 占位符提示
- **右侧操作区**：
  - **模型选择器**：`DeepSeek-V4-Flash High ▼`（下拉选择 Provider/模型）
  - **刷新按钮**（↻）：重新生成或刷新状态
  - **发送按钮**：蓝色圆形按钮（`#2563eb`），带向上箭头 ⬆️
- **背景**：白色，顶部 1px 边框 `#e5e7eb`，与消息区区分

### 3.6 底部状态栏（Bottom Status Bar）

固定在页面最底部，全局实时指标。

```
┌─ Bottom Status Bar ───────────────────────────────────────┐
│  18 轮 · 501 步 │ LLM 67分20秒 · 工具调用 12分7秒 │ 首 token 平均 1.9秒 · 157 tok/s │ 缓存命中 99.9% │
└───────────────────────────────────────────────────────────┘
```

**指标说明**：

| 指标                    | 数据源                                       | 说明                  |
| ----------------------- | -------------------------------------------- | --------------------- |
| `18 轮`               | `SessionAggregate.totalTurns`              | 总 Turn 数            |
| `501 步`              | `SessionAggregate.totalSteps`              | 总 Step 数            |
| `LLM 67分20秒`        | `Σ Step.usage.timing.totalMs`（LLM 调用） | 模型推理累计时间      |
| `工具调用 12分7秒`    | 工具执行累计时间                             | 沙箱/外部调用累计时间 |
| `首 token 平均 1.9秒` | `Σ Step.usage.timing.ttftMs / count`      | 平均首 token 延迟     |
| `157 tok/s`           | `SessionAggregate` 实时计算                | 当前输出 token 速率   |
| `缓存命中 99.9%`      | `cacheRead / inputTokens`                  | 缓存命中率            |

**设计要点**：

- 背景：`#f9fafb` 或 `#f3f4f6`，与主内容区区分
- 文字：`#6b7280` 次要文字，等宽数字
- 点击指标可展开详细趋势图（Sparkline）或跳转到审计面板
- 实时更新：SSE 推送 `session.aggregate.updated` 事件

## 4. 组件设计规范

### 4.1 通用组件

| 组件                | 用途       | 规范                                                 |
| ------------------- | ---------- | ---------------------------------------------------- |
| `MessageCard`     | 消息卡片   | 扁平设计，无圆角大边框，底部元数据栏，支持嵌套子卡片 |
| `ThinkingCard`    | 思考步骤   | 线条图标，可折叠，灰色文字，显示 tok/用时            |
| `CodeCard`        | 代码/工具  | 线条图标，嵌套 ToolCall，等宽字体，浅灰背景          |

## 5. 交互设计

### 5.1 核心交互流

**新建会话**：

1. 点击 Sidebar `➕ 新会话` 或 Top Bar `➕ 新会话`
2. 弹出 GoalContract 快速配置（可选，高级用户）
3. 输入框直接输入目标，按 `Enter` 发送
4. UI 立即创建 `UserInteractionRecord`，Sidebar 新增会话条目

**执行中**：

1. 消息区实时追加 Step 卡片（SSE 推送）
2. 思考 → 代码 → 工具调用 层级嵌套显示
3. 底部状态栏实时更新（轮数、步数、tok/s、缓存命中）
4. 需要审批时弹出 ApprovalModal

**结束后**：

1. Reflector 评估，消息底部显示最终状态
2. 用户可点击 👍/👎 评价
3. `UserInteractionRecord` 状态置 completed

### 5.2 快捷键

| 快捷键                   | 功能                     |
| ------------------------ | ------------------------ |
| `Ctrl/Cmd + N`         | 新建会话                 |
| `Ctrl/Cmd + Shift + N` | 从模板新建               |
| `Ctrl/Cmd + F`         | 搜索会话/工作区          |
| `Ctrl/Cmd + B`         | 折叠/展开 Sidebar        |
| `Ctrl/Cmd + D`         | 打开/关闭 Audit Drawer   |
| `Ctrl/Cmd + T`         | 切换 对话/轨迹 Tab       |
| `Esc`                  | 关闭弹窗/抽屉/取消运行   |
| `Enter`                | 发送消息（输入框聚焦时） |
| `Shift + Enter`        | 输入框换行               |

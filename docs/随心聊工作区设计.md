# 随心聊默认工作区设计

> 背景：随心聊（未选项目）此前没有工作区，运行时回退到进程 cwd（如 `apps/api`），工具落点错误。
> 本设计为随心聊引入一个**可配置、持久化**的默认工作区。

## 1. 工作区解析规则

**工具执行目录**（`ApiRuntimeService.harness()`）按优先级：

1. 用户已选项目工作区（`GET /api/workspaces/current` 的 `path`）；
2. **随心聊默认工作区**（本设计；未选项目时使用）；
3. 缺省 = `$MAZI_HOME/workspace`（即 `~/.mazi/workspace`）。

**对话窗口标题**（顶部栏）按会话上下文解析：

1. 项目会话 → 用会话自身记录的 `workspace`（即**当前项目工作空间**）；
2. 随心聊会话（无 `workspace` 归属）→ 用**随心聊默认工作区**，**不再回退到上次选中的项目路径**（避免旧项目路径污染标题）；
3. 无活跃会话（欢迎页 / Lab / Wiki）→ `已选工作区 || 随心聊默认工作区`。

**续聊提交**（`submitPrompt`）：续聊跟随会话自身工作区（随心聊会话不传 `workspacePath`，后端落在随心聊默认工作区）；仅全新会话使用当前选中工作区。

**不再回退 `process.cwd()`**（这是此前指向 `apps/api` 的原因）。

## 2. 默认值

- 默认 `$MAZI_HOME/workspace`，服务启动时自动创建。
- 选择理由：持久、语义明确、不会像 `/tmp` 那样被清理；`~/.mazi/tmp` 的“tmp”命名暗示可丢弃，不适合作为默认目录。
- 可在「设置 → General → Workspace」修改（输入路径保存，或用系统目录选择器）。

## 3. 持久化与接口

- 存储：`$MAZI_HOME/workspaces.json` 的 `freeChatWorkspace` 字段（与 `projects` 同文件）。
- `GET /api/workspaces/current` → 增加 `freeChatPath`。
- `POST /api/workspaces/free-chat` `{ path }` → 设置并持久化；空 → 回退默认。
- `POST /api/workspaces/pick-free-chat` → 系统目录选择器 + 设置。
- `GET /api/config`（`overview()`）→ 增加 `freeChatWorkspace`。

## 4. 运行时

- `ApiRuntimeService.harness()`：未选项目时 `new HarnessRuntime(config, { workspaceRoot: freeChatWorkspace })`。
- 修改默认工作区后重建运行时（`restartRuntimes`，执行中的会话不打断）。
- 工具执行目录同时入库到 `tool_call` step 的 `payload.cwd`（供审计展示完整路径）。

## 5. 前端

- `store.freeChatWorkspace`（来自 `/api/workspaces/current.freeChatPath`）。
- **顶部栏 TopBar** 内显示：会话名称 + 当前工作区；**自左侧边栏宽度（240px）处开始、贴着 topbar 下边框**；
  品牌与 slogan 位置不变。名称最多 12 个字符，超出省略号截断。
  - 项目会话：用会话自身的 `workspace`（即**当前项目工作空间**）；
  - 随心聊：**随心聊默认工作区**（不再回退到上次选中的项目路径）。
  - 前端 `workspaceRoot` 是全局「当前选中」缓存，不随会话切换而重置；因此标题区按会话上下文取值（见 §1），不直接读取该缓存。
  - 名称超长时以省略号截断（CSS ellipsis，悬停看全）。
- 设置页 General 新增「Free chat workspace」（显示当前值 + 输入/保存 + 选择…）。

## 6. 验收

- `apps/api/test/workspaces.controller.test.ts`：默认路径与目录创建、保存/空回退、`/api/config` 暴露。
- 前端（`apps/webui/src/App.vue`）：
  - 随心聊会话标题区显示**随心聊默认工作区**，而非上次选中的项目路径；
  - 随心聊会话续聊提交不携带旧项目路径（后端落在随心聊默认工作区）；项目会话续聊仍用会话自身工作区。

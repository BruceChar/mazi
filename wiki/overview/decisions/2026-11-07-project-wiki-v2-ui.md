# 项目 Wiki v2 界面与通用模板

## 背景

旧 WebUI 同时展示 v1 快照和编程项目黑板，初始化模板也以模块、代码和软件部署为中心。
这会让 v2 仓库内 wiki 在界面中不可见，并降低研究、写作、设计、运营等项目的适用性。

## 决策

- WebUI 主视图直接投影仓库内 `wiki/`：左侧文档索引、中间 Markdown、右侧当前状态与 claims。
- `/api/wiki` 保留旧字段，同时新增 `repository`，避免破坏既有调用方。
- `wiki.py init` 保持现有文件名，统一 overview 文档信息结构，并使用领域中立的标题和说明。

## 结果

- 项目 wiki 展示与 skill 维护的事实源一致。
- 已有 wiki 不需要迁移文件名；新项目获得可跨项目类型复用的模板。
- 旧快照和黑板数据仍可通过 API 读取，但不再主导 Wiki 页面。
